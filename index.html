    How to read the matrix

    Each row is a background color and each column a foreground (text) color, both sorted dark to light. A cell shows an “Aa” sample of the pair, its contrast ratio, and a badge for each WCAG requirement:

    AA-N
    Normal text, 4.5:1 (WCAG AA)
    AA-L
    Large text, 3:1 (WCAG AA)
    AAA-N
    Normal text, 7:1 (WCAG AAA)
    AAA-L
    Large text, 4.5:1 (WCAG AAA)
    ✓ Pass
    Meets that requirement
    ✗ Fail
    Does not meet that requirement

    Pairs below the ratio chosen above are left empty. A color that reaches it with no other color is removed from the matrix and listed above it. When there isn’t room for every column, the matrix becomes a list grouped by background color that shows only the pairs that reach the chosen ratio.

    Large text means at least 24 CSS pixels at regular weight, or about 18.7 CSS pixels bold. Ratios use the WCAG 2 relative luminance formula and are truncated, never rounded up, so a figure shown as 4.49:1 really does fail 4.5:1.
